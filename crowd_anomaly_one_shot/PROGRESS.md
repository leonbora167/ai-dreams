## Decisions log
- 2026-10-15, Phase 0: Retained Anaconda `pyt-dl` environment with PyTorch 2.8+cu128 and CUDA enabled on NVIDIA GeForce RTX 4060 (8GB).
- 2026-10-15, Phase 0: Acquired open benchmark sample videos per user instruction (PETS 2009 for normal crowd, UMN for crowd running/panic, AIRTLab CCTV for fight/violence, D-Fire/wildfire for fire/smoke).
- 2026-10-15, Phase 0: Set initial analysis dimensions to 960 width (aspect ratio preserved, resulting in 960x720 for 4:3 or 960x540 for 16:9) with GRID_H=12, GRID_W=20 giving ~48x60 (or 48x45) px per cell.
- 2026-10-15, Phase 1A: Selected OpenCV DIS as the default motion method (`MOTION_METHOD = "dis"`) running in ~28-54 ms on CPU. Also fully implemented FastFlowNet (pure PyTorch correlation, ~64-84 ms on GPU, weights in `weights/fastflownet_ft_mix.pth`) and RAFT-small (~110-138 ms on GPU), all selectable via `config.MOTION_METHOD`.
- 2026-10-15, Phase 1B: Approved CSRNet density-map counting model (`DENSITY_METHOD = "csrnet"`) for small head sizes in distant stadium CCTV. Pretrained weights `weights/csrnet_shanghaitech.pth` (65 MB). Measured 59-92 ms latency on GPU (~11-17 FPS). Count validated on PETS 2009 (predicted mean 7.0 vs ground truth 6-8).
- 2026-10-15, Phase 1C: Implemented multi-scale baseline fitting (`weights/baseline_cam01_12x20.npz`, `weights/baseline_cam01_24x40.npz`) and scoring with `SCORE_SMOOTH_WINDOW = 3`. Generated all 7 required visual outputs in `outputs/phase1c/`.
- 2026-10-15, Phase 1D: Configured gate parameters per user Step 0 preferences (`MIN_EVENT_SECONDS = 1.5`, `MAX_GAP_SECONDS = 1.0`, `LOW_THRESHOLD = 3.5`, `HIGH_THRESHOLD = 6.0`, `MIN_REGION_CELLS = 2`). Implemented connected component spatial clustering (8-way connectivity), IoU multi-scale box merging, temporal EMA box tracking, and two-level event classification (`confirm` vs `direct`). Emitted events conforming to contract in `outputs/phase1d/events.json`. Generated all visual outputs in `outputs/phase1d/`.
- 2026-10-15, Phase 1E: Built second gate in `src/gate.py` with logged reasons (`gate_reasons_table.md`) evaluating persistence, spatial neighbor support, and visual appearance novelty (MobileNetV3 feature embeddings, `weights/normal_emb_cam01.npz`). Implemented random audit sampler in `src/audit.py` with Wilson score 95% confidence intervals, emitting snippets and review manifest to `outputs/phase1e/audit_queue/`. Generated all required visual outputs in `outputs/phase1e/`.
- 2026-10-15, Phase 1E: Benchmarked MobileNetV3 vs CLIP (ViT-B/32) side-by-side for the second-gate appearance novelty check (`outputs/phase1e/appearance_model_comparison.png`). MobileNetV3 achieved a significantly sharper abnormal novelty separation margin (+0.377 vs +0.092 on crowd panic, +0.292 vs +0.224 on CCTV brawl) because low-level structural feature embeddings are more sensitive to localized clutter than zero-shot semantic text-space embeddings. Configured both options in `src/gate.py` selectable via `config.APPEARANCE_MODEL`.
- 2026-10-15, Phase 1F: Verified YOLOv8n Fire and Smoke detector (`weights/yolov8n_fire_smoke.pt`, 3.01M params, 9.57 ms GPU latency). Built `src/fire.py` with `load_fire_model`, `detect_fire_smoke`, `fire_events_from_detections` (temporal persistence tracking >= 3 detections), and classical `color_flicker_prefilter`. Configured pipeline in `config.py` (`FIRE_EVERY_N_FRAMES = 3`, `FIRE_CONF_THR = 0.25`, `FIRE_MIN_FRAMES = 3`). Tested on stadium normal validation footage (0 false alarms >= 0.15), hard negative CCTV, and developing wildfire video (early smoke detected at t=28.8s, peak conf 0.82). Emitted events with `source="fire"`, `level=None`, `origin="gate"` to `outputs/phase1f/events_fire.json`.
